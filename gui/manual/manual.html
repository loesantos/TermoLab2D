TermoLab2D

Termodinâmica partícula a partícula — manual de uso

O TermoLab2D simula, partícula por partícula, um gás em duas dimensões e mostra ao vivo as grandezas da termodinâmica e da teoria cinética: temperatura, pressão, entropia, calor, trabalho, distribuição de velocidades. A simulação roda em C++ (com OpenMP); a interface, em Python. Cada caso prepara um experimento clássico (expansão livre, efusão, teorema H, mistura, condução de calor, compressão por pistão…) com parâmetros que o usuário pode alterar.

1. Instalação e execução

O que é preciso

  • Python 3.10 ou mais recente, com numpy, matplotlib, PySide6 e pyqtgraph;
  • um compilador C++17 com OpenMP (g++) — ou um executável do simulador já compilado.

Linux: pacote .deb (Debian, Ubuntu, Mint e derivados)

sudo apt install ./termolab2d_1.0-1_amd64.deb

O apt instala junto as poucas bibliotecas gráficas do sistema de que o programa precisa. O TermoLab2D aparece no menu de aplicativos (categoria Educação/Ciência), com o manual em PDF como ação do ícone; no terminal, o comando é termolab2d. O pacote é autocontido — traz seu próprio Python, PySide6, numpy e pyqtgraph em /opt/termolab2d — e não interfere no Python do sistema. Para remover: sudo apt remove termolab2d.

Requisitos: 64 bits, glibc 2.28 ou mais recente (Debian 11+, Ubuntu 20.04+, Mint 20+). Cerca de 215 MB em disco.

Linux: a partir do código

Em distribuições recentes (Ubuntu, Debian, Mint), o pip não instala pacotes no Python do sistema. Use um ambiente virtual que aproveite os pacotes já instalados:

cd "pasta/do/TermoLab2D"
python3 -m venv .venv --system-site-packages
.venv/bin/pip install -r requirements.txt
.venv/bin/python interface.py

O compilador vem do pacote g++ (sudo apt install g++). Na primeira execução — e sempre que o código C++ for alterado — a interface compila o simulador sozinha. Também é possível compilar à mão com make.

Windows: instalador

Execute TermoLab2D-1.0-instalador.exe. Ele instala tudo o que é necessário — inclusive o Python e o simulador já compilado — só para o seu usuário, sem pedir senha de administrador, em %LOCALAPPDATA%\Programs\TermoLab2D. O programa aparece no menu Iniciar (com o manual em PDF e o desinstalador) e, se você quiser, na área de trabalho. Para remover: menu Iniciar → Desinstalar o TermoLab2D, ou Configurações → Aplicativos.

Requisitos: Windows 10 (versão 1903 ou mais recente) ou Windows 11, 64 bits. Cerca de 115 MB em disco.

O instalador não tem assinatura digital; por isso o Windows pode mostrar o aviso “O Windows protegeu o computador”. Clique em Mais informações → Executar assim mesmo.

Windows: a partir do código

py -m pip install -r requirements.txt
py interface.py

Sem compilador instalado, coloque um simulator.exe pré-compilado em bin\windows\. Com o MinGW-w64 instalado, a interface compila o simulador sozinha.

Onde a interface procura o simulador: variável de ambiente TERMOLAB2D_SIMULATOR → build/simulator (compilando se as fontes forem mais novas) → bin/<linux|windows>/.

3. Primeira simulação, passo a passo

  1. Na lista de casos, clique em Expansão livre (Joule).
  2. Leia a descrição: o gás começa equilibrado na metade esquerda da caixa e, em t = 0, a parede é retirada.
  3. Deixe os parâmetros como estão (1 500 partículas, interação WCA, temperatura 1).
  4. Em Velocidade de exibição, escolha “Tempo real” para acompanhar o movimento.
  5. Clique em Iniciar. Durante alguns segundos a barra mostra “Equilibrando o gás…”; depois as partículas começam a ocupar a metade direita.
  6. Observe: a entropia configuracional sobe até perto de ln 2 ≈ 0,693 (linha tracejada); a fração de partículas na direita vai a ½; a temperatura fica praticamente constante.
  7. Agora troque a Interação para Lennard-Jones e rode de novo: o gás esfria. Depois, Coulomb: o gás esquenta. Por quê? Veja a seção do caso.
  8. Para guardar o resultado: Arquivo → Salvar imagem da janela ou Exportar séries temporais (CSV).

7. Controle da execução

  • Iniciar gera a configuração, executa o simulador C++ e começa a desenhar. Enquanto a simulação roda, os parâmetros ficam bloqueados.
  • Pausar suspende de fato o simulador (ele espera a interface); Continuar retoma. Durante a pausa é possível ampliar gráficos, trocar a cor das partículas e marcar outros gráficos.
  • Parar encerra a simulação; os gráficos ficam como estão e podem ser exportados.
  • Trocar de caso durante uma simulação a interrompe.
  • Padrões restaura os valores padrão do caso atual.

8. Os casos, um a um

Em cada caso: objetivo, parâmetros próprios, o que observar e atividades sugeridas para aula.

8.1 Expansão livre (Joule)

Objetivo. Mostrar o aumento de entropia num processo irreversível e o efeito das interações na temperatura de um gás real.

Montagem. O gás é equilibrado numa faixa à esquerda (fração f da largura), atrás de uma parede temporária, retirada em t = 0. O gás se expande para o vácuo sem realizar trabalho e sem trocar calor: a energia interna se conserva.

Parâmetros próprios. Largura e altura da caixa (40 × 20); fração inicialmente ocupada f (0,5).

O que observar.

  • ΔSconf/Nk → ln(1/f) (ln 2 ≈ 0,693 para f = ½).
  • A temperatura depende da interação: WCA/sem interação — constante (gás ideal); Lennard-Jones — cai (≈ 1,00 → 0,92 em t = 20, com os valores padrão); Coulomb — sobe muito (≈ 1 → 6,7). É o sinal de (∂T/∂V)U = −(1/CV)[T(∂P/∂T)V − P].
  • Logo após a retirada da parede, a metade direita recebe primeiro as partículas mais rápidas (fica “quente”) e a esquerda esfria; depois as duas se igualam.
Atividades. (1) Compare as quatro interações e explique o sinal da variação de temperatura. (2) Use f = 0,25 e verifique ΔS → ln 4 ≈ 1,39. (3) Com 100 e com 3 000 partículas, compare as flutuações de Ndir/N no fim: por que o processo inverso nunca é observado com muitas partículas?

8.2 Efusão através de um canal

Objetivo. Relaxação ao equilíbrio entre dois reservatórios; separação entre equilíbrio mecânico (pressão) e térmico (temperatura).

Montagem. Uma parede central com um canal divide a caixa em duas câmaras; o gás começa todo na esquerda.

Parâmetros próprios. Largura e altura da caixa (40 × 20); altura do canal (6); espessura da parede (2).

O que observar.

  • Duas escalas de tempo. Primeiro a pressão se iguala: o gás da esquerda se expande e esfria (≈ 0,7); a câmara direita esquenta (≈ 2) com o jato que entra. Como n k T fica igual dos dois lados, a câmara quente tem menos partículas e Ndir/N estaciona perto de 0,3.
  • Depois, devagar, o calor atravessa o canal, as temperaturas se aproximam e Ndir/N → ½.
  • Sem interação: efusão de Knudsen — as partículas rápidas passam primeiro.
Atividades. (1) Meça o tempo para Ndir/N chegar a 0,25 com canais de altura 2, 4 e 8. Como ele depende da abertura? (2) Compare WCA com “sem interação”. (3) Aumente o tempo de simulação para 500 e acompanhe o equilíbrio térmico.

8.3 Relaxação para Maxwell (teorema H)

Objetivo. Ver a distribuição de Maxwell–Boltzmann surgir das colisões e a função H de Boltzmann decrescer.

Montagem. As posições são equilibradas; em t = 0 todas as partículas recebem o mesmo |v| = √(2kT/m), em direções aleatórias.

Parâmetros próprios. Largura e altura da caixa (40 × 20).

O que observar. O pico do histograma se alarga até a curva de Maxwell–Boltzmann em poucas unidades de tempo; H cai até o equilíbrio e não volta a subir; a temperatura (energia) não muda.

Atividades. (1) Use “sem interação”: a distribuição não relaxa. O que isso diz sobre a origem da irreversibilidade? (2) Reduza σ para 0,1 ou dobre a área da caixa: o tempo de relaxação muda como o livre caminho médio λ ≈ 1/(√2 n σ)? (3) Por que, com poucas partículas (100), H flutua em vez de decrescer suavemente?

8.4 Mistura de dois gases

Objetivo. Entropia de mistura e paradoxo de Gibbs.

Montagem. Espécie A (azul) equilibrada na metade esquerda, espécie B (laranja) na direita; a divisória é retirada em t = 0.

Parâmetros próprios. Caixa 20 × 20; partículas de cada espécie (400); “espécies idênticas”; razão de massas mB/mA; razão de diâmetros σB/σA.

O que observar. A entropia que distingue as espécies cresce até ln 2 por partícula; a que só olha para as posições não muda, porque a densidade já era uniforme. A mistura é difusiva: o tempo cresce com o quadrado do tamanho da caixa.

Atividades. (1) Marque “espécies idênticas”: a dinâmica é a de um único gás, mas a entropia “com cores” ainda cresce ln 2. Discuta o paradoxo de Gibbs. (2) Use razão de massas 4: qual espécie atravessa mais depressa? Compare com D ∝ √(kT/m). (3) Dobre o tamanho da caixa e compare o tempo de mistura.

8.5 Gás em equilíbrio

Objetivo. Distribuição de Maxwell–Boltzmann, flutuações e conservação de energia.

Parâmetros próprios. Caixa 20 × 16; tamanho do obstáculo central (fração de cada lado; 0 = sem obstáculo).

O que observar. O histograma de |v| coincide com f(v) = (v/σ²) exp(−v²/2σ²), σ² = kT/m; a temperatura flutua em torno de um valor constante; a energia total se conserva.

Atividades. (1) Compare as flutuações de T com 100, 400 e 1 600 partículas: dividem-se por 2 a cada fator 4? (2) Aumente dt para 0,005 e 0,01 e observe a energia total: qual é o maior dt aceitável?

8.6 Lei dos gases ideais

Objetivo. Medir a pressão mecanicamente e verificar P A = N k T (em 2D, a “área” faz o papel do volume); desvios do gás ideal.

Montagem. Caixa simples; a pressão é o impulso transferido às paredes por unidade de comprimento e de tempo.

Parâmetros próprios. Caixa 20 × 20 (padrão: 2 000 partículas, σ = 0,1).

O que observar. A pressão instantânea flutua muito; a média acumulada converge. Valores de Z obtidos com 2 000 partículas na caixa padrão e T = 1:

InteraçãoσZ
sem interação—1,00
WCA0,1≈ 1,09
WCA0,2≈ 1,42
WCA0,3≈ 2,43
Lennard-Jones0,2≈ 0,93 (T = 1); ≈ 0,61 (T = 0,6)
Atividades. (1) Varie N, T e o tamanho da caixa, anote ⟨P⟩ e faça o gráfico de P contra NkT/A. (2) Com WCA, explique Z > 1 pela área excluída (segundo coeficiente do virial B2 ≈ πd²/2). (3) Com Lennard-Jones, por que Z < 1 e por que o desvio aumenta quando T diminui?

8.7 Condução de calor entre paredes

Objetivo. Transporte de calor, estado estacionário e lei de Fourier.

Montagem. Parede esquerda quente, direita fria (paredes térmicas); paredes de cima e de baixo isolantes.

Parâmetros próprios. Caixa 40 × 20; temperatura da parede esquerda (2) e da direita (0,5).

O que observar. O perfil T(x) evolui até um gradiente estacionário, com “saltos” de temperatura junto às paredes. No estacionário as curvas de calor das duas paredes ficam paralelas e opostas: a inclinação é o fluxo de calor J. A densidade é maior do lado frio.

Atividades. (1) Estime a condutividade: κ ≈ J/(Ly |dT/dx|), onde J (energia por tempo) é N vezes a inclinação da curva de calor acumulado no estacionário e dT/dx vem da parte central do perfil. (2) Compare com “sem interação” (regime balístico): o perfil fica plano no meio? (3) Dobre a diferença de temperatura: o fluxo dobra?

8.8 Aquecimento de um gás pelas paredes

Objetivo. Relaxação térmica e a primeira lei sem trabalho (ΔE = Q).

Parâmetros próprios. Caixa 40 × 20; temperatura das quatro paredes (2). Padrão: gás a T = 0,3.

O que observar. T se aproxima da temperatura das paredes aproximadamente de forma exponencial; o gás esquenta primeiro junto às paredes; ΔE = Q o tempo todo.

Atividades. (1) Ajuste T(t) = Tp − (Tp − T0) e−t/τ aos dados exportados em CSV. (2) Como τ muda com o tamanho da caixa? E com σ? (3) Comece com o gás mais quente que as paredes (T = 4).

8.9 Compressão por pistão

Objetivo. Trabalho, processos adiabáticos e isotérmicos, reversíveis e irreversíveis.

Montagem. A parede direita é um pistão que, a partir de t = 2, se move com velocidade constante da posição inicial à final (frações da largura). A colisão com o pistão é elástica no referencial do pistão.

Parâmetros próprios. Caixa 40 × 20; posição inicial (1,0) e final (0,5) do pistão; velocidade (0,1); paredes fixas isolantes (adiabática) ou térmicas à temperatura inicial (isotérmica). Padrão: σ = 0,1.

O que observar.

  • Adiabática lenta: segue T A = cte e P A² = cte (γ = 2 para gás monoatômico em 2D). Reduzindo a área à metade, T ≈ 2,1 (ideal: 2,0).
  • Adiabática rápida (velocidade ≥ 1): o gás esquenta mais que a adiabática — processo irreversível, trabalho maior.
  • Isotérmica lenta: T quase constante; o calor sai pelas paredes (Q < 0); para o gás ideal, W/N = kT ln(A₀/A) = ln 2 ≈ 0,69 (a simulação dá um pouco mais, ≈ 0,78, porque o gás não é perfeitamente ideal nem perfeitamente isotérmico).
  • Posição final maior que a inicial: expansão, o gás esfria.
  • Em todos os casos, ΔE = Q + W.
O tempo de simulação é estendido automaticamente até o pistão parar (mais 5 unidades). Com o pistão rápido, dt é reduzido automaticamente. A compressão lenta (0,1) leva cerca de 200 unidades de tempo.
Atividades. (1) Compare velocidades 0,05, 0,2 e 1: em qual o caminho no diagrama P × A fica mais longe da adiabática? (2) Compare adiabática e isotérmica com a mesma velocidade; calcule o trabalho em cada uma. (3) Comprima e depois expanda (dois experimentos: 1,0 → 0,5 e 0,5 → 1,0): o gás volta à temperatura inicial?

8.10 Personalizado (geometria VTK)

Use qualquer máscara VTK 2D (legacy ASCII, STRUCTURED_POINTS, 0 = sólido, ≠ 0 = livre) e escolha a faixa da caixa ocupada em t = 0. Útil para meios porosos, obstáculos e canais. O script create_geometry.py gera caixas simples; a formatação está no README.

10. O modelo físico e as unidades

Dinâmica

Partículas em 2D, integradas por velocity Verlet. Paredes e sólidos refletem especularmente; paredes térmicas devolvem a partícula com velocidade sorteada na temperatura da parede (componente normal com a distribuição do fluxo, tangencial gaussiana). O pistão é uma parede móvel; a colisão é elástica no seu referencial (vx' = 2u − vx). Depois de t = 0 não há termostato.

Unidades reduzidas

Massa m = 1, constante de Boltzmann k = 1, energia ε = 1; comprimentos em unidades da caixa (σ = 0,2 por padrão). Com comprimento medido na unidade L, o tempo fica em unidades de L√(m/ε). “Temperatura 1” não é 1 kelvin: para um gás de argônio (ε/k ≈ 120 K), T = 1 com ε = 1 corresponde a cerca de 120 K.

Grandezas

  • Temperatura: T = K/(N k), com dois graus de liberdade por partícula (K = Σ ½mv²).
  • Pressão: impulso transferido às superfícies sólidas (e ao pistão) por unidade de comprimento e de tempo, médio entre dois quadros.
  • Gás ideal em 2D: P A = N k T; adiabática: T A = cte, P A² = cte (γ = 2).
  • Maxwell–Boltzmann 2D: f(v) = (v/σ²) exp(−v²/2σ²), σ² = kT/m; ⟨v⟩ = σ√(π/2).

Entropia e função H

A entropia é a estimativa de Boltzmann em grade grossa, mostrada como variação em relação a t = 0:

S_conf/(N k) = −Σ p_i ln(p_i / A_i)       (posições; células com cerca de 20 partículas)
S_vel/(N k)  = −∫ f(v) ln f(v) d²v        (histograma 2D das velocidades)
H            = ∫ f ln f d²v = −S_vel/(N k)

Ambas usam a correção de Miller–Madow para o viés de amostras finitas. Para um gás uniforme, Sconf → ln A; para Maxwell–Boltzmann, Svel = 1 + ln(2πkT/m). São estimativas: com poucas partículas elas flutuam e ficam ligeiramente abaixo do valor exato.

Limitações

  • As partículas são pontuais para as paredes (o diâmetro σ só vale entre partículas).
  • O potencial de Coulomb usa 1/r (como em 3D) restrito ao plano, com corte; não é a eletrostática logarítmica de um mundo 2D.
  • Os sólidos não blindam a interação: partículas interagem através de paredes finas se estiverem dentro do raio de corte.

11. Desempenho e precisão

  • Use Velocidade de exibição → Máxima para simulações longas; “Tempo real” limita o simulador ao ritmo da tela.
  • WCA e Lennard-Jones são rápidos; Coulomb é várias vezes mais lento (muitas vizinhas por partícula).
  • O custo cresce aproximadamente com N; dobrar N dobra o tempo.
  • Para resultados quantitativos, confira a energia total num caso isolado e reduza dt se ela variar mais que ~10⁻³.
  • Para médias melhores, rode várias vezes com sementes diferentes em vez de uma única simulação enorme.

13. Para o professor: novos casos e grandezas

  • Novo caso: em gui/scenarios.py, crie um Scenario com os parâmetros próprios (Param), a função build que gera a geometria e as chaves do .cfg, e, se quiser, valores teóricos em references. Acrescente-o a SCENARIOS; o formulário é montado sozinho. A descrição em HTML aparece no painel do caso; acrescente também uma seção a este manual (gui/manual/manual.html) com a âncora caso-<id>.
  • Nova grandeza: em gui/observables.py, crie uma subclasse de Observable (série temporal, distribuição ou perfil) e acrescente-a a OBSERVABLES.
  • Novas chaves do simulador (paredes, pistão, espécies…): ver o README.
